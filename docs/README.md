# ERP Management System — Documentation

A modern, minimal, multi-tenant ERP web application that centralizes business operations, employee management, finance, inventory and organizational activities in one platform.

**Stack:** Vite (vanilla JS) · Tailwind CSS v4 · Supabase (Postgres, Auth, Storage, Realtime)
