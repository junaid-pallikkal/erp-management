# Build discipline

- Create only what was asked. No extra pages, features, files, packages or settings.
- Have a better idea? Suggest it first and wait for an answer.
- Keep it simple. Choose the simplest solution that works.
- Reuse existing components before creating new ones.
- Don't refactor or change unrelated code.
- Ask before installing any new dependency.

## Hackathon mode
- We have 4 hours. A working, demo-ready flow beats perfect code.
- Build the main flow end to end first, then polish.
- Use realistic sample data so the demo looks real.
- Keep the app runnable at all times. Never leave it broken between tasks.
- Work in small steps. Update `docs/TASKS.md` after each one.
